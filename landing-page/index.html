Fractal GM-Opt

A General Purpose Subgraph Optimization Framework.

Define how candidate subgraphs are scored and explore them using neighborhood-search metaheuristics. Build on extensible search strategies and parallel execution through Fractal and Apache Spark.

The framework

A common foundation for different problems.

The objective function expresses the problem. Search strategies determine how candidate solutions are generated and explored.

01

Define your objective function

Score vertex-induced subgraphs using candidate and underlying-graph information. Supply your implementation as a Java class or a JavaScript file.

02

Extend the search

Integrate new metaheuristics, neighborhoods, and initial solution generation strategies through the framework’s code interfaces.

03

Explore in parallel

Optimize multiple initial solutions using the scheduling and graph-processing infrastructure provided by Spark and Fractal.

Current implementations

VNS, ILS, and TS; vertex addition, removal, and swapping; and random-walk-based initial solution generation. These are starting points, not the limits of the framework.

Express your problem

Start with a scoring function.

This example scores a subgraph by its number of edges divided by its number of vertices. Larger scores are preferred.

Replace the calculation with your own objective function. Java and JavaScript implementations use the same candidate representation.

Learn to implement an objective function →
density.js JavaScript example 
// Return edges per vertex without modifying the candidate.
function evaluate(subgraph) {
    var vertices = subgraph.getNumVertices();

    if (vertices === 0) {
        return 0.0;
    }

    return subgraph.getNumEdges() / vertices;
}

An Experimental Study of Variable Neighborhood Search for General-Purpose Subgraph Optimization in Parallel Systems

Diogo Carvalho, Mayron Moreira, and Vinícius Dias

An experimental study of parallel Variable Neighborhood Search for connected subgraph optimization, examining solution quality, scalability, and computational bottlenecks.
